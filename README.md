Moonpetal Heist — a complete original top-down stealth game: you are Pip, a moth-thief stealing moonpetals through a lantern-lit garden over seven nights. Lantern Keepers sweep vision cones across the paths; shadow bushes and tall grass hide you; lantern-light exposes you. Learn the patrols, distract keepers with pollen puffs, never let the bell toll, and slip out through the Moon Gate — unseen. Glimmer buys Mothcraft upgrades between nights; three moth-seals per night reward unseen, perfect and swift play.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. WASD or arrows to move, Shift to run, C to sneak, Q (or right-click) to throw a pollen puff, Esc to pause, M to mute.
